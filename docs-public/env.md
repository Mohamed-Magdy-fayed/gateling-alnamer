# Environment variables

Generated by `npm run check:env -- --markdown` from `.env.example`. Do not edit by hand.

| Key | Description |
| --- | --- |
| `APP_MODE` | Copy to .env for local development (`npm run env:init`, which also generates the secrets). Never commit real values. Runtime mode, required, no default: demo (mocks, demo accounts) or live (real providers only). |
| `DATABASE_URL` | Postgres for local development (the `db` service in docker-compose.yml). Required. |
| `BASE_URL` | Public origin; required on deployed environments, e.g. https://alnamer.gateling.com |
| `TEST_DATABASE_URL` | Throwaway test database for `--test-db` (blank = postgres://alnamer_test:alnamer_test@localhost:5433/alnamer_test). Must be a local host. |
| `DEMO_HOSTS` | Comma list of hosts allowed to run APP_MODE=demo with VERCEL_ENV=production. |
| `DEMO_ACCOUNTS_PASSWORD` | Demo only: shared password for the seeded demo accounts. Refused in live. |
| `DEMO_TOTP_SECRET` | Demo only: TOTP secret for the seeded staff accounts. Refused in live. |
| `PAYMENT_PROVIDER` | Payment provider: mock or myfatoorah (demo default mock; live must be myfatoorah). |
| `VIDEO_PROVIDER` | Video provider: mock, sample or bunny (demo default mock; live must be bunny). |
| `STORAGE_DRIVER` | Storage driver: local or firebase (demo default local; live must be firebase). |
| `EMAIL_TRANSPORT` | Email transport: smtp or mailpit (mailpit sends to localhost:1025; live must be smtp). |
| `JOBS_MODE` | Jobs mode: inline, inngest-dev or inngest (live must be inngest). |
| `INNGEST_EVENT_KEY` | Inngest event key: required when JOBS_MODE=inngest and whenever APP_MODE=live. |
| `INNGEST_SIGNING_KEY` | Inngest signing key: required when JOBS_MODE=inngest and whenever APP_MODE=live. |
| `INNGEST_ENCRYPTION_KEY` | Inngest encryption key: encrypts job payloads at rest in Inngest; required when APP_MODE=live (env:init generates a local one). |
| `INNGEST_DEV` | Set to 1 to use the local Inngest dev server (docker compose service `inngest`); never on Vercel. |
| `SMTP_HOST` | SMTP host: Mailpit locally; the real provider on deployed environments. |
| `SMTP_PORT` | SMTP port: 1025 is Mailpit. |
| `SMTP_USER` | SMTP user: blank for Mailpit. |
| `SMTP_PASSWORD` | SMTP password: blank for Mailpit. |
| `SMTP_FROM_EMAIL` | Sender address of outgoing email. |
| `SMTP_FROM_NAME` | Sender display name of outgoing email. |
| `UPSTASH_REDIS_REST_URL` | Redis REST proxy URL (the `redis-rest` service in docker-compose.yml). |
| `UPSTASH_REDIS_REST_TOKEN` | Redis REST token; must equal LOCAL_REDIS_TOKEN locally (env:init generates both). |
| `LOCAL_REDIS_TOKEN` | Token the local `redis-rest` proxy accepts (generated by env:init). |
| `CAPTCHA` | Captcha provider: fake or turnstile (demo default fake, which accepts any token; live must be turnstile, which needs both Turnstile keys). |
| `TURNSTILE_SITE_KEY` | Cloudflare Turnstile site key (public), used when CAPTCHA=turnstile. Cloudflare's always-pass test key is 1x00000000000000000000AA (always-fail: 2x00000000000000000000AB). Real keys are a human step. |
| `TURNSTILE_SECRET_KEY` | Cloudflare Turnstile secret key, used when CAPTCHA=turnstile. Cloudflare's always-pass test secret is 1x0000000000000000000000000000000AA (always-fail: 2x0000000000000000000000000000000AA). |
| `IBAN_ENCRYPTION_KEY` | 32-byte base64 key that encrypts teacher IBANs at rest (generated by env:init). |
| `TOTP_ENCRYPTION_KEY` | 32-byte base64 key that encrypts staff TOTP secrets at rest (generated by env:init). |
| `AUTH_SECRET` | 32-byte base64 root secret for the verification-code hashes, rate-limit keys and the rp and did cookies (generated by env:init). Required when APP_MODE=live or on Vercel. |
| `DB_USER` | Local Docker only: Postgres user of the `db` service. |
| `DB_PASSWORD` | Local Docker only: Postgres password of the `db` service. |
| `DB_NAME` | Local Docker only: Postgres database name of the `db` service. |
